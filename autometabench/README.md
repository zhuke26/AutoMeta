# AutoMetaBench

AutoMetaBench is an evaluation benchmark for **literature search, literature screening, data extraction, and meta-analysis reproduction**. It connects review questions to included-study references, fixed screening pools, extracted quantitative results, and published pooled estimates. The release includes the numerical reference data together with a source-audit ledger and a read-only drift checker.
